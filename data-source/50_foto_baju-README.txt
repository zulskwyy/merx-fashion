PAKET KOLEKSI 50 FOTO BAJU

Sumber: Pexels.
Koleksi ini dibuat berdasarkan permintaan foto baju dengan tampilan mendekati contoh:
- tampak depan / product-style bila tersedia
- background polos/minimalis
- tanpa model untuk sebanyak mungkin item
- campuran t-shirt, polo, hanger, flat lay, dan beberapa foto dengan model karena stok gratis yang benar-benar identik jumlahnya terbatas.

Isi paket:
1. 50_foto_baju.csv       -> daftar 50 sumber + direct image URL
2. download_50_baju.sh    -> script Mac/Linux untuk mengunduh semua foto

Cara download di Mac:
1. Unzip paket ini.
2. Buka Terminal.
3. Masuk ke folder paket.
4. Jalankan: ./download_50_baju.sh
5. Hasil ada di folder: foto/

Catatan:
- File gambar tidak dapat saya unduh langsung ke runtime ini karena koneksi keluar dari lingkungan kerja dibatasi.
- Script di atas menggunakan direct image URL dari Pexels dan akan mengunduh file JPG ke komputer Anda.
- Periksa kembali lisensi/kebijakan penggunaan Pexels untuk kebutuhan komersial tertentu.
