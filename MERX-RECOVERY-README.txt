MERX FULL RECOVERY PACKAGE

This package is a complete project tree assembled from the last complete MERX
project archive plus the persistent admin session / wallet upgrade.

IMPORTANT:
1. Do NOT extract this archive over the existing merx-ecommerce folder.
2. Create a NEW empty folder, extract this ZIP there, and then use that folder
   as the replacement project.
3. Keep your existing .env values separately. This package does not contain
   production secrets.
4. After extraction, run git status and inspect the tree before replacing your
   current local project.
